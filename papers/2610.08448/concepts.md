# 概念词条

状态统一为：已讲解，待检查。没有作答证据，不标记已掌握。

## 老师模型 / 学生模型

两个 AI 模型的教学角色：老师提供参考，学生通过训练调整自己。本文老师固定，学生更新。

易混淆：老师不是人，也不保证每次判断都正确。

原文位置：§2.1，PDF 第3页；[PDF](https://arxiv.org/pdf/2610.08448v1)

## 知识蒸馏

让学生模型借助老师模型提供的指导来学习。可以先想成老手带新手。

易混淆：比喻不等于直接复制老师全部知识或参数。

原文位置：§1–2，PDF 第2–4页；[PDF](https://arxiv.org/pdf/2610.08448v1)

## On-Policy Distillation（OPD）

学生先按自己当前的能力生成回答，老师针对学生已经写到的内容提供下一步的参考，训练学生。

易混淆：不是老师先写好整篇范文让学生照抄；老师的指导包含下一块文字的概率。

原文位置：§2.2，PDF 第3页；[PDF](https://arxiv.org/pdf/2610.08448v1)

## token / tokenizer

token 是模型处理文字的小块；tokenizer 是把文字切成这些块并转换为编号的工具。

易混淆：一块不一定是一个汉字或一个完整单词；切分不等于理解。

原文位置：§2.3，PDF 第3–4页；[PDF](https://arxiv.org/pdf/2610.08448v1)

## 对齐

比较两个模型时，先确认比较的是同一段文字及对应候选项。

易混淆：同一段文字可被切成不同数量的小块，不能只按第几个块硬比。

原文位置：§2.3，PDF 第3–4页；[PDF](https://arxiv.org/pdf/2610.08448v1)
